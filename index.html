Perch

A pocket client for a Hermes Agent you host yourself. Your address, your key, your machine.

Perch talks to one thing: the gateway you point it at. There is no relay, no account and no backend of ours in the path — which is not a privacy promise so much as a description of the architecture, and it is why the privacy policy is as short as it is.

What it does

  • Follow a run as it happens, with reasoning and tool calls in line.
  • Answer an approval from the lock screen before the command runs.
  • Sessions, routines, skills and toolsets — read anywhere, changed where the gateway allows it.
  • Look around with no gateway at all: walkthrough mode renders every screen from captured responses.
